# VIM Hotkey Trainer (C++)

Консольный тренажёр горячих клавиш Vim, написанный на современном C++ для Linux/macOS. Проект демонстрирует работу с терминалом в raw mode, RAII, конечным автоматом состояний, разделением ответственности между модулями и созданием TUI без внешних библиотек.

## Возможности

- Мгновенная обработка нажатий клавиш без ожидания Enter (raw mode)
- 10 уроков: базовая навигация, работа со словами и строками, прокрутка, поиск
- Подсветка прогресса: введённые, текущая и оставшиеся клавиши
- Прогресс-бар, статистика уроков и нажатий
- Цветной интерфейс на ANSI escape-кодах
- Безопасное восстановление настроек терминала через RAII
- Низкие зависимости: стандартная библиотека C++ и POSIX termios

## Архитектура

| Модуль | Ответственность |
|---|---|
| `main.cpp` | Точка входа, обработка критических исключений |
| `Application` | Главный цикл приложения, связывает UI, ввод и движок |
| `TrainerEngine` | Игровая логика: состояния, уроки, проверка ввода, статистика |
| `Lesson` | Модель данных одного урока |
| `TerminalUI` | Отрисовка: очистка экрана, центрирование, рамки, цвета |
| `TerminalGuard` | Управление режимом терминала и чтение символа без буферизации |

```text
main.cpp
  └── Application::run()
        ├── TerminalGuard      // включает и восстанавливает raw mode
        ├── TrainerEngine      // хранит состояние и правила игры
        ├── TerminalUI         // выводит интерфейс
        └── getch()            // читает одну клавишу
```

## Сборка и запуск

```bash
g++ -std=c++17 -Wall -Wextra -O2 \
    main.cpp Application.cpp TerminalGuard.cpp TerminalUI.cpp TrainerEngine.cpp \
    -o vim_trainer

./vim_trainer
```

Проект использует POSIX API (`termios`, `read`), поэтому предназначен для Linux и macOS.

## Управление

| Клавиша | Действие |
|---|---|
| `1`–`9` | Выбрать урок 1–9 |
| `0` | Выбрать урок 10 |
| `q` / `Q` | Выйти из меню или приложения |
| `ESC` / `q` во время урока | Вернуться в меню |
| `n` / `Space` после урока | Перейти к следующему уроку |
| `m` / `q` после урока | Вернуться в меню |

## Ключевые технические решения

### RAII для терминала

`TerminalGuard` в конструкторе сохраняет исходные настройки терминала и включает raw mode. В деструкторе настройки восстанавливаются. Даже если программа завершится исключением, терминал не останется в нестандартном режиме.

### Конечный автомат

`TrainerEngine` использует `enum class AppState`:

- `MENU` — выбор урока
- `PLAYING` — прохождение урока
- `LESSON_COMPLETE` — экран успешного завершения
- `EXIT` — завершение работы

Это делает логику предсказуемой: для каждого состояния есть собственный обработчик ввода и функция отрисовки.

### Разделение ответственности

Логика не знает, как именно рисуется интерфейс: `TrainerEngine` вызывает методы `TerminalUI`. Модель урока (`Lesson`) отделена от движка и интерфейса.
