# VIMHotkeyTrainer_cpp
Тренажер горячих клавиш для VIM на С++

========================

- Работает на Linux/macOS 
- Сырой ввод (RAW MODE) (Мгновенная реакция на нажатия клавиш)
- RAII (Безопасное управление ресурсами терминала: гарантия возврата настроек при сбросе)
- ANSI Colors (Terminal User Interface без тяжелых библиотек)

========================

1. TerminalGuard (RAII): Управляет сырым режимом терминала, чтобы считывать нажатия клавиш без ожидания нажатия Enter.Гарантирует вовзрат терминала в нормальное состоянии при выходе или ошибке
2. TerminalUI: Отвечает за отрисовкуа (очистка экрана, цвета, вывод текста)
3. Lesson: Модель данных. Хранит названия, описания и целевую последовательность клавиш
4. TrainerEngine: Мозг приложения. Хранит состояния,обрабатывает ввод, проверяет правильность и переключает уроки
5. Application. Главный класс, который связывает все компоненты и содержит главный цикл
